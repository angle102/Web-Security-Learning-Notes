# Nessus / OpenVAS


# 一、Nessus

## 1.1 工具定位

Nessus 是常用的商业漏洞扫描工具。

主要作用：

```text
资产漏洞扫描
系统补丁检查
中间件漏洞识别
弱口令风险检测
配置风险检查
合规基线检查
生成扫描报告
```

简单理解：

```text
Nessus = 自动化漏洞扫描与风险评估平台
```

---

## 1.2 使用场景

Nessus 常用于：

```text
1. 内网资产漏洞扫描
2. 服务器补丁检查
3. 中间件漏洞扫描
4. Web 服务基础漏洞识别
5. 数据库暴露风险识别
6. 运维基线检查
7. 渗透测试前期风险梳理
8. 渗透测试报告辅助证据
```

---

## 1.3 常见扫描类型

| 扫描类型                  | 使用场景       |
| --------------------- | ---------- |
| Basic Network Scan    | 基础网络漏洞扫描   |
| Advanced Scan         | 自定义扫描策略    |
| Web Application Tests | Web 应用基础测试 |
| Credentialed Scan     | 带凭据主机扫描    |
| Malware Scan          | 恶意软件检查     |
| Compliance Scan       | 合规检查       |

---

## 1.4 使用流程

基本流程：

```text
1. 新建扫描任务
2. 输入目标 IP 或网段
3. 选择扫描模板
4. 配置端口范围
5. 配置认证信息，按授权范围决定
6. 启动扫描
7. 分析漏洞结果
8. 人工复核高危漏洞
9. 导出报告
10. 整理修复建议
```

---

## 1.5 Nessus 结果分析

扫描结果通常包括：

```text
漏洞名称
风险等级
CVE 编号
受影响主机
受影响端口
漏洞描述
修复建议
插件输出
证据详情
```

风险等级常见为：

```text
Critical
High
Medium
Low
Info
```

注意：

```text
Nessus 扫描结果不能直接等于真实漏洞。
必须结合版本、配置、访问路径和人工验证进行确认。
```

---

## 1.6 报告中如何体现

可以整理为：

| IP           | 端口   | 服务     | 漏洞名称        | 风险 | 修复建议      |
| ------------ | ---- | ------ | ----------- | -- | --------- |
| 192.168.1.10 | 443  | HTTPS  | TLS 配置风险    | 中  | 禁用弱加密套件   |
| 192.168.1.20 | 8080 | Tomcat | 默认页面暴露      | 低  | 删除默认页面    |
| 192.168.1.30 | 6379 | Redis  | Redis 未授权访问 | 高  | 限制访问并设置认证 |

# 二、OpenVAS / Greenbone

## 2.1 工具定位

OpenVAS 是开源漏洞扫描工具，后来逐渐发展为 Greenbone Vulnerability Management 体系的一部分。

主要作用：

```text
开源漏洞扫描
网络资产风险发现
系统服务漏洞识别
弱配置检查
漏洞报告输出
```

简单理解：

```text
OpenVAS = 开源版漏洞扫描与风险评估工具
```

---

## 2.2 使用场景

OpenVAS 常用于：

```text
1. 学习漏洞扫描流程
2. 内网资产基础扫描
3. 与 Nessus 扫描结果交叉验证
4. 服务器风险检查
5. 漏洞修复前后对比
6. 安全实验室环境建设
```

---

## 2.3 基本使用流程

使用流程：

```text
1. 安装 OpenVAS / Greenbone
2. 初始化漏洞库
3. 创建扫描目标
4. 创建扫描任务
5. 选择扫描策略
6. 启动扫描
7. 查看漏洞结果
8. 导出报告
9. 人工复核漏洞
```

---

## 2.4 扫描结果分析

OpenVAS 结果一般包括：

```text
漏洞名称
风险等级
CVSS 分数
受影响主机
受影响端口
检测结果
漏洞描述
修复建议
参考链接
```

常见风险等级：

```text
High
Medium
Low
Log
```

---

## 2.5 Nessus 与 OpenVAS 对比

| 对比项  | Nessus    | OpenVAS / Greenbone |
| ---- | --------- | ------------------- |
| 类型   | 商业工具      | 开源工具体系              |
| 上手难度 | 相对较低      | 配置稍复杂               |
| 漏洞库  | 较完整       | 开源可用                |
| 报告能力 | 较强        | 可满足学习和实验            |
| 适合场景 | 企业扫描、项目交付 | 学习、实验、辅助扫描          |
| 注意事项 | 需要授权和许可   | 需要维护漏洞库             |

---

## 2.6 使用注意

```text
漏洞扫描器容易产生误报
扫描前必须确认授权范围
生产环境应控制扫描时间和扫描强度
扫描结果需要人工复核
不要只依赖扫描器判断漏洞存在
```
